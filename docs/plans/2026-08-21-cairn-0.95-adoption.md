# Cairn 0.95.0 adoption and chassis sync

**Branch:** `cairn-0.95-adoption`. **Token ceiling:** 3M. **Checkpoint:** after every two tasks.
**Execution:** five tasks, so the per-task chain runs through the Agent tool (implementer,
`diff-reviewer`, gate), not the workflow.

## Why

The site sits on `^0.94.0`; `0.95.0` is the published stable. The release carries no mandatory
consumer step for this site except one: `@anthropic-ai/sdk` became an optional peer, and this
Worker sets `ANTHROPIC_API_KEY` (the tidy action is in use), so the site must add the SDK to its
own dependencies. Two type tightenings may surface at `check` time (`SiteConfig` no longer
indexable by a dynamic key; `AdminShellData` gains a required `mediaBase`). The release also ships
the share-a-draft preview feature: its "Share preview" group appears in every editor on the
single-mount facade, but a minted link only works once the site mounts `/preview/[token]` and
applies `migrations/0003_preview.sql` to `AUTH_DB`. Shipping the control without the route would
hand an editor a broken link, so adoption is part of this pass.

The showcase chassis (`cairn-cms/examples/showcase/src/chassis/`) gained five files since this
site scaffolded: `public-routes.ts`, `entry-data.ts`, `archive.ts`, `date.ts`, `dev-gate.ts`, plus
additions to `render.ts` (the prose-typography seam), `theme-toggle.ts` (the flip cross-fade),
and `tokens.css` (the DaisyUI component `exclude` list). Of those, this site takes what it has a
use for and records the rest as deliberate omissions in `src/chassis/README.md`.

Left alone, by decision: `src/chassis/prose.css`. It diverged through this site's own design
passes (h2 at 700, the B1 h4 subheads, the reading-size base), all locked verdicts in
`docs/design-benchmark/`. Re-syncing it against the showcase is a design pass with a before/after,
not a migration step. `archive.ts` (the posts page groups by year without pagination),
`entry-data.ts` (no concept here declares a reference field), and `dev-gate.ts` (this site runs no
dev backend) are omitted.
